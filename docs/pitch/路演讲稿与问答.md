## 一、提交用文字

**项目名称**：AIQUANT TERMINAL —— AI 投研一站式研究与交易市场

**项目介绍（150 字版）**
AIQUANT TERMINAL 是一个已上线运行的 AI 投研网站。它让大模型在规则约束下反复迭代地提出投资因子（Loop Engineering），用样本外留出、多重检验校正与交易成本门禁把「回测漂亮但不能赚钱」的信号筛掉，再把通过检验的因子送入端到端量化流水线生成目标持仓与交易单，并从上线日起样本外跟踪、每日自动监控推送。研究者可以把通过检验的策略与因子上架到内置市场，用银行卡或加密货币交易，平台以分成、订阅与机构 API 变现。

**项目介绍（一句话版）**
让 AI 挖出可交易的 Alpha，并让它经得起检验、卖得出去。

**「输入—处理—输出」流程说明**
输入一句投资假设（或选择一个市场）→ AI 闭环挖掘 + 遗传进化并行搜索，评估器逐条打分并把拒绝理由反馈给下一轮 → 输出带五项评级的因子报告卡、目标持仓与交易单，可一键部署为模拟持仓或上架销售。全程在线上环境真实完成。

## 二、10 分钟讲稿（按页计时）

> 语气原则：讲「已经做到了什么」和「接下来要放大什么」。不讲开发曲折、不讲亏损与失败案例、不说「还没做」；被问到未完成项时用「路线图上 Q4 完成」的口径回答。

### P1 封面（0:00–0:40）
各位导师、各位投资人，下午好。我是 Presley，今天带来的项目是 AIQUANT TERMINAL。一句话：它是一个已经上线运行的 AI 投研网站，让 AI 提出投资因子，用一套严格的样本外检验把噱头筛掉，再把通过检验的信号变成交易单，并且允许研究者把它挂到市场上卖。接下来 10 分钟讲三件事：为什么现在做、我们做了什么、为什么值得投。

### P2 痛点（0:40–1:40）
过去投研的瓶颈是「产生想法」。今天一个大模型一分钟能写出一百条因子表达式，这一步的成本已经归零。瓶颈转移到了两处：第一，可信的验证——研究员仍然在 Excel、脚本和回测框架之间手工搬数据，验证一条因子要半天；第二，过拟合成了行业默认——试得越多，随机撞中的假信号越多，绝大多数漂亮的回测扣掉成本、换手和样本外衰减之后归零。还有第三点：信号上线之后没有人持续盯着，回测与实盘的差距悄悄拉大。谁能把「AI 生成 → 严格验证 → 持续监控」做成一条自动化流水线，谁就掌握了 AI 时代投研的关键环节。

### P3 解决方案总览（1:40–2:40）
这就是我们的答案，也是今天现场要演示的流程。输入：一句投资假设，或者选一个市场——美股 118 只、加密货币 40 个币，还支持小时级。处理：Claude 提出因子表达式，确定性的评估器打分，把「为什么被拒」写成指令送回下一轮；同时一台不依赖大模型的遗传进化引擎并行搜索。检验：五项评级、随累计试验次数上升的显著性门槛、扣成本后价差为正的可交易门禁，只有 A/B 级才放行。输出：多因子组合、目标持仓、交易单，模拟持仓从上线那天起样本外跟踪，每天自动监控推送；也可以一键上架销售。

### P4 产品全景（2:40–3:30）
左边是线上首页的真实截图。四个模块一句话带过：行情终端与诚实回测——下一根开盘成交、双边成本、永远对照买入持有；AI 因子挖掘与 Kronos 预测——两台挖掘引擎，加一个公开滚动准确率的开源 K 线基础模型；端到端量化流水线——从宇宙到交易单；交易市场与钱包。重点是这四块接在同一套数据和引擎上：市场里买的策略一键进回测，因子库的因子一键进流水线，流水线结果一键部署成模拟持仓。一体化，是我们和单点工具的差别。

### P5 核心技术一：Loop Engineering（3:30–4:30）
我们把方法论叫 Loop Engineering。AI 不是一次性生成，而是在确定性评估器和规则约束下反复迭代。四步：提出——在安全的 DSL 里写表达式，自研解析器，永不执行任意代码；评估——秩 IC、留出集、换手、成本后价差、t 统计量；反馈——把拒绝理由写成指令：别重复、别相似、换方向；记忆——因子库与错题本跨会话带入。右下角是第二台引擎，遗传进化，不依赖大模型；两台引擎找到同方向的因子时，可信度倍增。

### P6 核心技术二：五道门禁（4:30–5:30）
这一页是我们与竞品最大的区别。AI 生成因子已经不稀缺，稀缺的是把过拟合、不可交易、随机撞中的因子拦下来。五道门禁：预测力、稳定性、稳健性、可交易、显著性，每一条因子都拿到一张报告卡——右边是真实页面。举个例子：一个回测 IC 很高、但 Top-5 每天换六成仓位的因子，扣成本就是负的，门禁直接拦下，并把理由反馈给 AI 下一轮避免。对投资人的意义：市面上「一键生成因子」把筛选责任丢给用户，我们把筛选做成产品核心，还公开上架因子的上线后成绩。信任，是这个市场最稀缺的东西。

### P7 从因子到交易单再到每一天（5:30–6:15）
研究成果不停留在报告。流水线给出目标持仓与调仓单，用 CPCV 交叉验证与多重检验校正后的 Sharpe 报告风险；模拟持仓按真实日期部署，NAV 从那天起回放，一切都是样本外；服务器每个交易日收盘后重算，五类告警推送到 Slack、Discord、Telegram。对投资人的含义：用户留存来自「每天都要回来看」，而不是一次性工具。

### P8 现场演示（6:15–6:45 讲解 + 约 3 分钟演示）
接下来我用三分钟走一遍真实流程。第一步输入：因子挖掘页，美股、10 日持有期，假设「成交量放大后的价格突破会延续」。第二步处理：启动闭环，看 AI 提出、评估器打分、拒绝理由反馈，旁边遗传进化在跑进度。第三步输出：点开报告卡看五项评级，把通过门禁的因子「→ Pipeline」生成目标持仓与交易单，一键部署成模拟持仓，或者上架到市场。

**演示准备清单**
- 提前登录线上站点；用同一假设提前跑一次，缓存命中加载更快。
- 因子库预留 2–3 条已通过门禁的因子，保证第三步一定有输出。
- 网络不佳时的兜底：直接展示因子库 → 报告卡 → 流水线结果页（这三页无需等待挖掘）。
- 演示总时长控制在 3 分钟内；超过 2 分半就跳到输出环节。

### P9 商业模式（6:45–7:30）
三层收入。第一层市场分成，已经上线：研究者上架策略或因子，买家用银行卡、Apple Pay 或加密货币购买，平台收 10% 手续费，服务器签发权益凭证，配退款争议与审计日志。第二层 Pro 订阅，今年四季度：更高的挖掘额度、小时级市场、严格模式、每日监控推送。第三层机构 API 与白标，明年：把「挖掘—门禁—流水线」给券商投顾、FOF 和教育机构。右边是飞轮：越多人挖掘，评估器和记忆越强，越多高质量因子进入市场，越多买家。研究工具本身就是获客漏斗。

### P10 市场（7:30–8:00）
三组公开数据：中国 A 股个人投资者账户超过 2.2 亿；全球加密货币持有者超过 5 亿；一个 Bloomberg 级终端每席位每年约 2.5 万美元，我们的定价目标是它的百分之一。三类客群：独立交易员与量化爱好者，愿为「确定性」付费；小型私募、FOF 与投顾，需要可审计的流程；金融教育与高校——这个产品已经被用作 15 分钟因子挖掘课的教学演示，自带课堂模式。AI 让研究能力民主化，但专业级的验证与监控工具是空白，这就是我们的位置。

### P11 壁垒（8:00–8:40）
三重壁垒。验证方法论：留出集、CPCV、多重检验校正、可交易门禁、因子家族去重、边际贡献，每一项都有论文依据并落地成功能，不是白皮书。信任层：服务器签发凭证、退款争议、只追加的审计日志、上架因子的公开成绩、分级管理令牌——一个「敢让别人在上面花钱」的市场。工程质量：后端 283 个自动化测试、28 条端到端浏览器测试、前后端契约测试全部进 CI，每次提交自动部署。别人可以复制一个「AI 生成因子」的按钮，很难复制一整条经得起审计的流水线。

### P12 进展与里程碑（8:40–9:10）
四个真实数字：12 个核心模块全部上线；118 只美股加 40 个币的标的宇宙，含小时级；80 多个公开 API 端点；311 个自动化测试。路线图重点是四季度：开通真实支付、首批 50 名上架研究者、Pro 订阅上线、接入 A 股。这是从「产品」到「生意」的转折点。

### P13 融资需求（9:10–9:40）
天使轮 300 万元人民币，18 个月。用途：研发与数据 45%，A 股与多市场行情、移动端、AI 算力；市场与社区 30%；合规与运营 15%——支付与资金合规我们非常重视；储备 10%。18 个月目标：注册研究者 1 万、付费转化 5%，上架 1000 条策略因子、月交易额 50 万，2 家机构 API 试点，三市场全覆盖，启动 Pre-A。

### P14 收尾（9:40–10:00）
回到开头那句话：AI 时代的投研，瓶颈不在想法，而在可信的验证。AIQUANT TERMINAL 把「AI 提出 → 严格检验 → 交易执行 → 持续监控 → 市场交易」做成了一条已经在线运行的流水线。邀请各位和我们一起，把它做成 AI 投研时代的基础设施。网址在屏幕上，现在就能试。谢谢，欢迎提问。

## 三、导师 / 投资人常见问题与答法（10 分钟互动）

**Q1 AI 挖因子不就是数据挖掘？必然过拟合。**
我们不否认过拟合，而是把学术界对抗过拟合的全部工具做成默认开启的产品功能：样本外留出、CPCV 组合式净化交叉验证、显著性门槛随累计试验次数上升的多重检验校正、扣成本的可交易门禁、因子家族去重。附录 A 每一项都能在产品里点开。更重要的是上线后：模拟持仓从部署日起全部样本外，服务器每天重检并公开成绩，衰减会被标出来。

**Q2 你们的 Alpha 到底赚不赚钱？有实盘业绩吗？**
我们是研究与交易基础设施，不是资管产品；我们卖的是「可信的验证与执行流程」，不是某一条信号的收益承诺。平台上每条上架因子都带公开的上线后成绩，买家用数据自己判断。这也是我们与卖信号的「大 V」模式的根本区别——我们不需要押某一条信号，而是从所有研究活动中收费。

**Q3 大模型公司或券商为什么不做？**
大模型公司做通用能力，不做垂直的验证与交易闭环，也不会为一个细分市场维护多源行情、成本模型和每日运维。券商受合规与组织约束，不会开放一个让个人研究者互相买卖策略的市场。我们的位置是两者中间：方法论产品化 + 开放市场的信任机制，这两者叠加需要时间和真实运行数据。

**Q4 用户凭什么付费？免费工具很多。**
免费的是「生成」，付费的是「确定性」：更高挖掘额度、小时级市场、严格模式、每日监控推送——这些直接对应研究者的时间与风险。市场层的付费更直接：买一条通过门禁、带公开成绩的因子，比自己从零挖掘便宜得多。

**Q5 合规风险？卖策略算不算投资建议？**
平台交易的是策略参数与因子表达式这类研究工件，不是投资建议，也不托管客户资金；支付走 Stripe 与 Coinbase Commerce 的托管页面，卡号与私钥不经过本站；权益凭证、退款争议、审计日志都已实现。融资用途里专门有 15% 用于合规与法律意见，Q4 会完成合规架构确认。

**Q6 数据从哪来？成本多高？**
美股与加密的行情来自多个免费公开源（Binance、Yahoo、CoinGecko、Stooq、AkShare）做三重冗余，加三层缓存与每日预热，边际成本接近零；AI 调用按用量计入 Pro 订阅额度。未来接入 A 股会引入付费数据源，已计入研发与数据预算。

**Q7 团队多大？技术能否维持？**
整套系统按无服务器架构设计，每日运维、重检、监控、真实数据夜测全部由 GitHub Actions 自动完成，一名工程师即可维持；311 个自动化测试与契约测试保证迭代安全。融资用于市场、数据与商业化，而不是堆运维人力。招募计划：一名量化研究 + 一名增长运营。

**Q8 估值与出让？**
天使轮 300 万元，建议出让 10%–15%（按此口径准备，可现场按实际调整）。18 个月内以经营指标（研究者数、付费转化、市场交易额、机构试点）启动 Pre-A。

**Q9 为什么先做美股与加密，而不是 A 股？**
两个市场公开数据完整、24×7（加密）便于验证方法论；A 股已在四季度路线图上，因子 DSL 与流水线与市场无关，接入是数据层工作而非重写。

**Q10 竞品是谁？**
上游：Bloomberg / Wind 等终端（贵、无 AI 闭环、无开放市场）；平行：各类「AI 选股 / 一键生成因子」应用（无验证门禁、无上线后成绩）；下游：策略信号订阅社区（不可审计）。我们把三者中缺失的「验证 + 执行 + 信任」连成一条流水线。
